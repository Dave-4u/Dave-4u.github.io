Thread-Safe LRU Cache

Least-recently-used cache with O(1) get/put, reentrant locking, hit/miss stats, and a multi-threaded stress demo.

API

cache = ConcurrentLRUCache(capacity=32)
cache.put("user:1", profile)
profile = cache.get("user:1")
print(cache.stats.hit_rate)

Highlights

  • Ordered map for recency + hash lookup
  • Correct under concurrent readers/writers
  • Eviction, refresh-on-get, and capacity checks covered by tests

Run

cd projects/concurrent-lru
python demo.py
python -m unittest test_lru.py -v
