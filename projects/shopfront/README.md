# ShopFront

Responsive e-commerce storefront demo built with HTML, CSS, and vanilla JavaScript.

## Features

- Product catalog with categories, search, and sort
- Product detail modal
- Shopping cart with quantity controls
- Cart persistence via `localStorage`
- Checkout form with client-side validation
- Fake order success screen (no real payments)

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
