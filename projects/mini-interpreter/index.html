Miniature Interpreter

A small expression language implemented end-to-end: lexer → recursive-descent parser → AST → evaluator, with unit tests.

Pipeline

  • Lexer — numbers, identifiers, operators, parentheses
  • Parser — precedence, right-associative ^, assignments
  • Evaluator — environment for variables, runtime checks

Example

x = 10;
y = x * 2 + 1;
y;          → 21

Run

cd projects/mini-interpreter
python demo.py
python -m unittest tests/test_interpreter.py -v
python -m src.interpreter   # REPL
