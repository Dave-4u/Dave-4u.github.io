TellMe

Location-based mobile application for community information sharing.

Overview

TellMe helps people share and discover local information in their community. The Android client is built with Kotlin and Jetpack Compose for a modern, responsive interface, with Firebase providing backend data and core services.

Stack

  • Kotlin
  • Jetpack Compose
  • Firebase

What I built

  • Designed and implemented the application for community information sharing
  • Developed the UI with Jetpack Compose
  • Integrated Firebase for application data and core functionality
  • Tested and evaluated features for stability and component integration
